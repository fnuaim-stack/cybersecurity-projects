# Roadmap

No strict schedule here. This is just the list I will use when deciding what to build next.

## Things I want to improve

- make the network scanner faster without making the code ugly
- add packet filters and better summaries to the packet analyzer
- support a few more real log formats
- let the file integrity monitor save a change report
- make the vulnerability dashboard able to add and edit findings
- eventually connect the dashboard to a small backend instead of only browser storage
- add tests when a project gets enough logic to need them

## New project ideas

- DNS lookup and record checker
- simple IOC checker for hashes, IPs, and domains
- small PCAP summary tool
- web security header history checker
- basic CVE notes/search helper using public data
- local port/service inventory tool

I will keep the repo on the defensive side and focus on stuff that is useful for learning blue-team and vulnerability-management work.
